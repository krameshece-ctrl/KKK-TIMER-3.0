Hello everyone. Welcome to my KKK timer. This is completely made by me. This is a free web tool where you can improve and record your times. I am glad that this timer could help you.

Take this timer as motivation. Please use this timer correctly and purposefully.

Let's come to the point. I will explain how to use this timer. First choose your cube. You will see the scramble given above. Scramble your cube exactly and press the spacebar 0.5sec to start the timer. Press the spacebar again to stop the timer. You can delete the times if you want. You can also enable inspection time.

I made this timer inspired by cs timer. although this timer is not complex as cs timer, you can use this for practices. I hope you will find this as one of the best timer.

PC Keyboard Controls

Hold Spacebar (0.5s) Arm Timer
Release Spacebar Start Solve / Inspection
Press Any Key Stop Timer

Mobile Touch Controls

Touch & Hold Screen (0.5s) Arm Timer (Red -> Green)
Release Finger Start Solve / Inspection
Tap Anywhere While Running Stop Timer Instantly
15s Inspection Time
